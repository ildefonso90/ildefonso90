## 👨🏾‍💻 Professional Overview & Engineering Profile

I am an **undergraduate Computer Engineering student** based in Angola, focusing on **Systems Administration, Software Engineering, AI Workflows, and Enterprise Management Platforms**.

My engineering approach bridges system-level work with application architecture. Whether developing desktop management software in C#, building cross-platform mobile apps with Flutter, or creating automation and media workflows, I prioritize **practical solutions, performance, and reliability**.

### 🛠️ Core Focus Areas
* ⚙️ **Systems Administration & Networking:** Linux environments, networking, DNS, terminal tooling, and deployment utilities.
* 🤖 **AI & Automation Pipelines:** AI-assisted content workflows, automation scripts, and system integrations.
* 📦 **Enterprise Systems:** Inventory management, POS software, stock control, and business software logic.
* 📱 **Cross-Platform & Web Apps:** Mobile and web applications using Flutter, Dart, JavaScript, and .NET.
